技术落点

React · Flask · JWT · MySQL

四个技术节点共同支撑身份传递、权限判断与业务数据保存。

React 负责界面、登录状态与受保护页面。

JWT 传递可信身份。

Flask 在后端再次判断权限。

MySQL 保存用户、角色与酒店业务数据。
